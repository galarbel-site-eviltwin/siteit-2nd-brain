# פרומפט ל-Claude Design: אנימציית המוח במסך קליטת המידע

לצרף לפרומפט את הלוגו: `docs/logo.png` (או `docs/mockup/assets/mark.png` למשולש בלבד).

---

אני צריך אנימציה של "מוח" למסך קליטת מידע באפליקציה פנימית בשם SiteIt 2nd Brain. זה המוח הארגוני של סוכנות קידום ובניית אתרים: העובדים גוררים אליו שיחות וואטסאפ, תמלולי פגישות, הצעות מחיר והקלטות, והוא לומד אותם. מצורף הלוגו, וממנו צריכה לצאת כל השפה הוויזואלית.

**מה האנימציה צריכה להעביר:** שהמידע לא נזרק לתיקייה אלא נכנס למוח שמבין ומחבר. המוח קולט, מעבד, ומחבר את הפריט החדש למה שהוא כבר יודע.

**השפה הוויזואלית, לפי הלוגו:**
- המוח בנוי מקווים ומעגלים, כמו אייקון המוח ומסלולי המעגל החשמלי שבלוגו: קווי מתאר לבנים או שזיף, צמתים עגולים בקצוות, קווים ישרים עם פינות של 45 מעלות. לא מוח ורוד ריאליסטי, ולא ענן זוהר.
- אפשר ומומלץ לשלב את משולש ה-play של הלוגו (למשל המוח יושב בתוך המשולש, או שהמשולש נבנה מהקווים בסוף העיבוד).
- צבעים, בדיוק מהלוגו:
  - שזיף `#311C57` (צבע ראשי)
  - ירוק `#1AD689` = וואטסאפ והודעות
  - תכלת `#01B3FD` = פגישות והקלטות
  - צהוב `#FDD509` = מסמכים והצעות מחיר
  - ורוד `#F1086A` = החלטות
- לכל צבע יש משמעות קבועה במערכת. כשנגרר קובץ וואטסאפ, המסלולים שנדלקים הם ירוקים. כשנגרר מסמך, צהובים. לא לפזר את כל הצבעים סתם לקישוט.
- בלי גרדיאנטים סגולים זוהרים, בלי glow ניאון, בלי חלקיקים אקראיים שמרחפים בלי סיבה. נקי, גרפי, שטוח, עם עומק מינימלי.

**ארבעה מצבים, שאפשר להחליף ביניהם מבחוץ** (דרך `data-state` על האלמנט הראשי):
1. **`idle` (ממתין):** המוח שקט. תנועה עדינה מאוד שמראה שהוא "ער": צומת אחד או שניים שנדלקים לאט בתורות, מחזור של כ-4 שניות. זה רוב הזמן על המסך, אז זה חייב להיות רגוע ולא מעייף.
2. **`hover` (קובץ נגרר מעל האזור):** המוח מגיב מיד (200ms, ease-out): נפתח או מתרחב מעט, וכל המסלולים שמובילים פנימה נדלקים, כאילו הוא "מושיט יד" לקובץ.
3. **`processing` (אחרי שחרור הקובץ):** נקודות מידע נכנסות מלמעלה, זורמות לאורך מסלולי המעגל אל תוך המוח, וצמתים נדלקים בשרשרת בצבע של סוג הקובץ (משתנה `--src-color`). נמשך בלולאה עד שמגיע `done`.
4. **`done` (נקלט):** פעימה אחת קצרה: כל הצמתים מהבהבים פעם אחת, קו חדש "מצטייר" ומחבר את הפריט החדש לרשת הקיימת, וסימן וי קטן מופיע. בערך 800ms, ואז חזרה ל-`idle`.

**דרישות טכניות:**
- קובץ HTML אחד עצמאי: SVG אינליין + CSS + מעט JavaScript. בלי ספריות חיצוניות, בלי Lottie, בלי תמונות.
- רקע שקוף. צריך להיראות טוב גם על רקע בהיר (`#F5F2FA`) וגם על כהה (`#110822`). קווי המתאר מקבלים את הצבע ממשתנה CSS (`--ink`), כדי שיתחלפו לבד בין המצבים.
- גודל 240 עד 320 פיקסלים, מתכוונן לפי רוחב האלמנט (viewBox, בלי מידות קבועות).
- מבצעים: להנפיש רק `transform`, `opacity` ו-`stroke-dashoffset`. לא להנפיש width, height או filter כבד.
- עקומות: כניסה ותגובה עם `cubic-bezier(.23,1,.32,1)`. תנועה על המסך עם `cubic-bezier(.77,0,.175,1)`. בלי ease-in.
- `prefers-reduced-motion`: בלי זרימה ובלי לולאות. רק שינוי צבע ושקיפות בין המצבים.
- API פשוט: `brain.dataset.state = 'processing'` ו-`brain.style.setProperty('--src-color', '#1AD689')`.

**מה להחזיר:**
1. את הקובץ, עם שורת כפתורים לבדיקה (idle / hover / processing / done) ובורר צבע מקור (וואטסאפ, פגישה, מסמך, הקלטה).
2. תצוגה של האנימציה על רקע בהיר ועל רקע כהה, זה לצד זה.
3. שתי וריאציות שונות של הרעיון (למשל: מוח בתוך משולש ה-play, ומוח שהמשולש נבנה מהקווים שלו), כדי שאוכל לבחור.
